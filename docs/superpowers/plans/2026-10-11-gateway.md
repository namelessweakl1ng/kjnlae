# Gateway Implementation Plan

**Goal:** Deliver functional detection and independent enforcement with real evaluation.
**Architecture:** Standalone guard, server-owned authorization, bounded optional CPU model worker, SQLite metadata, FastAPI and React.
**Tech Stack:** Python 3.12, Pydantic, FastAPI, Transformers optional, pytest, Ruff, mypy, React/Vite.
**Spec:** ../specs/2026-10-11-gateway-design.md

## Global constraints
No paid API or model required. No unsafe remote code. No raw sensitive content retained by default. Direct main push without force. No external benchmark claims.

## Review focus
Unicode offsets, encoded budget exhaustion, forged identity, approval replay/parameter mutation, unavailable classifier fail closed.

## Tasks
- [ ] Core: tests/unit/test_detection.py pins original spans, negatives, decoding and limits; implement schemas, normalization, rules and Guard.scan.
- [ ] Enforcement: tests/security/test_authorization.py pins ownership, exact intent, destinations and one-use approval; implement ActionGateway and OutputGuard.
- [ ] ML: tests/unit/test_classifier.py pins timeout and unavailable status; implement spawned worker and optional real smoke test.
- [ ] Application: integration tests pin auth, limits, retention and laboratory; implement API, CLI, SQLite and scenarios, then build React dashboard.
- [ ] Evaluation: metric tests pin confusion matrix and denominators; original fixtures, BIPIA export adapter and AgentDojo integration documentation.
- [ ] Delivery: lint/type/test/build/audit, functional HTTP checks, documentation, Docker/CI, commit and verify origin/main.
