# kjnlae design

Build a local Python 3.12 security gateway and React dashboard. Core modules do not depend on HTTP. Rules inspect original and bounded derived views with original evidence spans; contextual analysis is a caller claim, never authorization. Decisions are ordinal risk scores, not calibrated probabilities.

Independent action authorization consumes server-owned principals, intent grants, ownership, tool and destination constraints. Approval is random, expiring, one-use, and bound to a canonical exact action digest and principal. Clients cannot supply authority. Output screening checks configured exact secrets and allowed link destinations. Sensitive actions deny when required controls are unavailable.

Optional Transformers classification executes in a spawned CPU worker with deadline termination, bounded tokens/windows/batches and no remote code. Exact revision and explicit positive label are mandatory. No weights are redistributed; unavailable ML yields explicit incomplete inspection and review.

FastAPI exposes bounded authenticated APIs with local loopback defaults, rate limiting, metadata-only SQLite retention, safe error handling, no raw prompt logs. Production disables laboratory endpoints and requires credentials. Frontend uses escaped React text and real results. Original regression fixtures and sandbox metrics are illustrative, not external accuracy claims.

Verification covers authorization forgery, parameter mutation, expiry/replay, encoded evidence, limits, model failure, API authentication, persistence, metrics and browser-safe rendering. Docker/CI use the same package/build commands. User authorized implementation and direct non-force push to main; no PR and no live external action demo.
