# v0.2 training data provenance

The committed `datasets/fixtures/v2_seed.jsonl` contains 100 original, fictional English examples: 64 TRAIN, 12 VALIDATION, 12 CALIBRATION, and 12 HELD_OUT_TEST. It contains 50 injection and 50 non-injection examples. The latter include educational quotations, source code, ordinary employee/patient access requests, and permitted reads. These labels describe **prompt-injection behavior in the stated source**, never the caller's authorization. The 30 v0.1 regression fixtures are excluded from training.

The optional public TRAIN source is Microsoft BIPIA's `benchmark/text_attack_train.json`, pinned to Git commit `a004b69ec0dd446e0afd461d98cb5e96e120a5d0` and source SHA256 `63f95d3e67eac4178cdabdbdaf192cd05f2b6ed0702b578f1d30d556e5155670`. The importer selects 50 active instruction-shaping entries from ten categories and labels them as untrusted retrieved content. It excludes BIPIA's ordinary information requests and all external context corpora. We do not copy BIPIA into this repository. Its repository is MIT licensed for Microsoft-authored material, with separate dataset licenses and NOTICE for third-party components; the selected attack-prompt file is treated as Microsoft-authored. Users should retain BIPIA's LICENSE and NOTICE when importing it. BIPIA was archived in September 2026, so this pinned import is a frozen reference, not a maintained benchmark feed.

The final experiment also imports `deepset/prompt-injections`, pinned to revision `4f61ecb038e9c3fb77e21034b22511b523772cdd`. Its dataset API advertises Apache-2.0, while nested dataset metadata says CC BY 4.0. We satisfy the attribution and notice obligations of **both** declarations, retain the exact source/revision/hashes, and do not redistribute its rows. The pinned train parquet SHA256 is `2e10bc7ab30f542c97e4e83e2a5683000b5057d25ec10908784c631d44124c04`; the official test parquet is `39ac797cabc157eeed58435a08593b2952bb6cb16fc394a2d383f447cc7b246e`. If the differing declarations cannot be reconciled for a downstream redistribution, seek legal review before distribution. AgentDojo is an external evaluation integration candidate; none of its data is in the present training partitions.

All original partition families are disjoint. The importer rejects cross-partition family, normalized text and near-duplicate leakage, and writes per-source and per-split SHA256 manifests. Public BIPIA examples are TRAIN-only; they cannot tune thresholds or report held-out scores. The tiny original held-out set measures software behavior on its specific examples and cannot establish broad real-world accuracy. Similarity to upstream encoder pretraining data is unknown. There are no real patient or company records.

To reproduce the first full model-only training manifest, follow the pinned source acquisition, import and preparation commands in [model training](model-training.md). Those commands regenerate the 660/12/12/116 partition without using the exploratory original held-out examples. The original filtered source SHA256 is `85c354093f58e2be018e2fbcd06143d1d6f200b4523b317a3d36f3c3baab281c`.

The first exploratory manifest had 114 TRAIN, 12 VALIDATION, 12 CALIBRATION and 12 original HELD_OUT_TEST examples. Its high false-positive rate led to a second, separately recorded experiment. The earlier full-run manifest has 660 TRAIN (64 original, 50 BIPIA, 546 Deepset), 12 original VALIDATION, 12 original CALIBRATION and 116 Deepset HELD_OUT_TEST examples. The original exploratory test examples were excluded from the second manifest. They remain a diagnostic, not part of the official held-out score. The official Deepset train/test split was fixed upstream and checked for exact, normalized, near-duplicate and family leakage locally; upstream construction and possible pretrained-encoder overlap are not independently verified. The 116-case result describes this source distribution, not general prompt-injection performance. Revalidate the pinned commits and source SHA256 values before using them; a later clone or revised dataset is a different experiment.

## Experimental follow-up partition

The new 50-case original independent evaluation set was committed at `1a307c5` before new training data were prepared. It contains 35 benign and 15 attack cases, is MIT licensed as part of this repository, and has SHA-256 `a70629b432dda5ad0a6a91ba87a35bffd594752af7d7ab1d39f2f29ee34438bc`. It is excluded from every training/calibration split. The old 30-case regression set is also excluded.

The follow-up TRAIN partition contains the prior 660 rows plus 64 newly authored fictional benign TRAIN examples from `datasets/fixtures/v0.2-benign-train.jsonl` and 200 deterministic source variants of existing Deepset public **TRAIN benign** examples. The authored file is MIT licensed, SHA-256 `2f846ed89ab8b9d9111e27c927289c6e91734de9880c6487dc1cfe908b2e91c1`. The variants retain the public text, label, family and Deepset attribution; only their source metadata changes. `python -m kjnlae.training.augment` with seed 43 produces local SHA-256 `277998b7e770a29c5e49e805e0a8cb103717b73e50cbef0a4a9d23c36ed57346`. Public-source license obligations therefore still apply; the generated variants are not redistributed in Git. This source balancing is an experimental distribution intervention, not new independent content.

The new prepared counts are **924 TRAIN / 12 VALIDATION / 12 CALIBRATION / 116 HELD_OUT_TEST**. TRAIN SHA-256 is `a20fe7bd4e2a1d7fbd5da81d68a81ce37b52e724ff7a272aa7c4b7145bb911af`; the other three split SHA-256 values remain `dba1dd1a859aebcf4ab4caa36ff3ee29efb4a266d77cbbfaec95eb9f6aa544c2`, `54563c39a4a8189ef6e88eb9697001a759504dd5ad343ab28d8d01a9dec3243b`, and `99663b36168ce67f5fa59ee9bb7ac4f6af39309df543cb98e989cfb5ad4c9552`. Exact normalized overlap between the new independent set and old TRAIN/regression cases was zero before training. This check cannot establish semantic independence or exclude overlap with encoder pretraining.
