The release benchmark used the unchanged original 30-case regression fixture with the reviewed model. It measured **TP 17, TN 3, FP 9, FN 1**, precision `0.6538`, recall `0.9444`, F1 `0.7727`, benign FPR `0.7500`, false-negative rate `0.0556`, and full 30/30 coverage. The scripted defense measured four of four unauthorized actions denied, two of two authorized tasks completed, and zero observed attack successes; it uses synthetic proposals/callbacks and no live LLM. The previously frozen 50-case independent comparison and held-out Deepset measurements remain in [follow-up evaluation](reports/v0.2-followup-evaluation.md); they were not rerun for this code-only refactor. The model's serious false-positive behavior remains unresolved.

For a fresh target environment, run the [platform quickstart](../README.md), `kjnlae model verify`, `kjnlae doctor`, a complete `kjnlae scan`, dashboard submission, and `bash scripts/verify_all.sh` where Bash is available. Actual-weight tests require `KJNLAE_TEST_MODEL_DIR` and `KJNLAE_TEST_MODEL_HASH`; skipped tests are not proof of model inference. Hosted CI intentionally has no weights and can only test explicit incomplete/degraded behavior. Full AgentDojo/BIPIA external benchmarks, a fresh Fedora installation of this refactor, Windows/macOS real-weight inference, and a production identity deployment remain unverified.

The later main-integration PR also adds an HTTP Unicode/JSON body-size regression: valid 32,768-codepoint strings can require more than 128 KiB when escaped as JSON. The new strict 512 KiB limit is covered by a full-length accepted-input test plus an oversized-request rejection test. These new tests passed together with the full [six-job main-integration CI run](https://github.com/namelessweakl1ng/kjnlae/actions/runs/38592651086): Python 3.12/3.13, frontend, Docker and Windows/macOS no-weight portability. The earlier 94/6 **local actual-weight** test totals predate these additional integration tests; do not conflate the two evidence sets.
