# Evaluation method and provenance

`python -m kjnlae.maintainer_cli train evaluate --fit ... --prepared ...` compares a seeded pretrained DistilBERT encoder with **untrained classifier head** against the genuinely fine-tuned model. The same separate CALIBRATION partition selects each threshold; the HELD_OUT_TEST partition measures the frozen results. The control is not an injection detector. [The measured report](reports/v0.2-model-evaluation.md) records confusion matrices, precision, recall, F1, FPR/FNR, CPU forward time, weights and split hashes.

`python -m kjnlae.maintainer_cli benchmark --output reports/benchmark` scans the original 30-case regression fixtures through the **current sole model**, writes JSON and Markdown, and runs six scripted boundary cases. `--dataset datasets/fixtures/v0.2-independent-eval.json` runs the new 50-case authored fixture frozen before follow-up tuning. It reports completeness, latency, confusion matrix, per-category metrics and prevention outcomes only when model inference completed for all cases. Missing weights yield `INCOMPLETE` and no accuracy estimate. The historical [fixture report](reports/v0.2-fixture-benchmark.md) measured 10 false positives among 12 benign examples for the original artifact. The [follow-up comparison](reports/v0.2-followup-evaluation.md) records both artifacts and both authored sets; the new candidate still has 10 false positives among 35 new benign cases.

Detection precision/recall/F1/FPR/FNR use explicit true/false labels. Defense attack-success and unauthorized-action prevention use observed synthetic callbacks, not model predictions. Authorized completion and benign rejection are separately measured. A model that blocks an educational quotation can prevent a task even when there is no attack. The sandbox uses scripted proposals and synthetic effects, not a live LLM, real account or external benchmark. Forward-pass latency excludes worker startup and API overhead; the fixture benchmark measures end-to-end scan latency on a warm worker after its first case.

Original authored fixtures are MIT licensed and synthetic; public BIPIA attack prompts and Deepset rows stay external and hash-pinned. See [data provenance](model-data.md). The small validation/calibration partitions and source-specific held-out test limit inference. The development process observed an earlier original 12-case test, then expanded training; this adaptive process is disclosed and the earlier cases were excluded from the final test. The 30-case suite was measured after first promotion and was not used for training or threshold selection. The 50-case fixture was committed before follow-up tuning and also stayed out of TRAIN/VALIDATION/CALIBRATION. Further tuning needs another untouched evaluation set.

BIPIA's archived prompt file is an optional lawful import path; AgentDojo can be integrated by passing its retrieved/tool content to `/v2/scan` and routing proposed tools through `ActionGateway`, while preserving AgentDojo's own scenario splits and license. Neither external benchmark was executed end-to-end for this release. Historical rule metrics in the original baseline report are research evidence only; the current application does not execute a rule detector.
