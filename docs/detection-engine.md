# Model-only detection

The sole injection detector is the project's experimental English DistilBERT fine-tuned from `distilbert/distilbert-base-uncased` revision `12040accade4e8a0f71eabdb258fecc2e7e948be`. Install the reviewed public artifact with `kjnlae model download`. Runtime requires a pinned, evaluated manifest, matching per-file hashes, expected labels, positive trained-step count, `EXPERIMENTAL` quality status, and safetensors weights. It never downloads during inference, loads remote code, accepts pickle weights, or substitutes lexical signatures or an untrained head.

Preprocessing creates original, Unicode-normalized, HTML-entity, and selected bounded Base64 views with mappings into the original input. These transformations **do not classify** content. The CPU worker tokenizes every view into overlapping windows (default 128-token limit and 32-token overlap), checks a maximum-window budget, batches inference, and reports every score and source span. The scan score is the maximum window injection-class softmax value. `evidence` is the subset of scored windows at/above the manifest threshold. Window highlights are coverage evidence, not causal token explanations.

Oversized input is rejected. Excess derived views, missing/corrupt weights, unscanned windows, timeout, and worker failure result in explicit `INCOMPLETE` or error. A partial inspection cannot be cleared. `InputPolicy` applies the verified threshold plus trusted application context; it makes no keyword-based injection decision. An ordinary request for another employee's record is an access-control question, even if the model assigns a score. Grant decisions remain with the host-owned resource and action controls.

The reviewed artifact's threshold is `0.025134501978754997`, selected on a separate calibration set. It is **not** a calibrated real-world probability. The reviewed model still overflags benign text: the independent 50-case authored fixture had 10 false positives among 35 benign cases, and the earlier 30-case regression set had 9 among 12. See [model data](model-data.md), [measured follow-up](reports/v0.2-followup-evaluation.md), and [limitations](limitations.md).
