# Model-only detection engine

The sole v0.2 prompt-injection classifier is our English DistilBERT fine-tuned in the first full run on 660 TRAIN examples and in the experimental follow-up on 924 TRAIN examples. It starts from `distilbert/distilbert-base-uncased` revision `12040accade4e8a0f71eabdb258fecc2e7e948be`. Runtime requires an evaluated local `manifest.json` with a pinned SHA256, matching file hashes, expected labels, positive checkpoint trained-step count and safetensors weights. The current model's `EXPERIMENTAL` quality status is explicit and is not a production quality approval. Older manifests with `approved: true` load for compatibility but are reported as `LEGACY_EXPERIMENTAL`; that historical flag was not a quality gate. Runtime never downloads a model during scanning, executes remote model code, or substitutes a rule detector or seeded untrained head.

Preprocessing applies bounded Unicode normalization, HTML entity and selected Base64 decoding with offsets mapped to original input. These transformations **do not classify** content. The worker tokenizes every view into overlapping 128-token windows (32-token overlap), checks its maximum window budget, batches CPU inference and returns model scores and mapped window spans. If an input is oversized, an encoding budget is exceeded, a window is unscanned, the worker times out, or weights are missing/corrupt, the result is explicit `INCOMPLETE` or validation error. Decoded content is never executed. Evidence highlights model windows, not proven attack phrases.

`InputPolicy` uses the model's threshold from its calibration manifest and trusted host context. It blocks suspicious lower-trust content; authorized user analysis may be warned. User-provided `context_ref` grants no authority. Untrusted text cannot change a principal, tenant, source grant or approval. Scanner classification is not a resource-access decision: a benign employee-record request may still be denied by ACL, and a positive model result does not prove the attack succeeded.

The training pipeline separates TRAIN, VALIDATION, CALIBRATION and HELD_OUT_TEST; the latter is untouched until promotion. The follow-up candidate measured FPR 16.1% on the Deepset test, 28.6% on the new 50-case authored fixture, and 75.0% on the original 30-case regression fixture. Do not present either score as universal accuracy. See [training](model-training.md), [source provenance](model-data.md) and [evaluation](reports/v0.2-model-evaluation.md). Meta Prompt Guard 2 has access/license requirements; the Protect AI DeBERTa project is archived. Neither is a v0.2 runtime fallback. A future GPU DeBERTa experiment needs separate approval, training and evaluation.
