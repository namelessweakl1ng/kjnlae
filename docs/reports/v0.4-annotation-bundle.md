# v0.4 independent-label candidate bundle

No candidate labels from it have been used for training, calibration, threshold selection or release claims. The bundle lives outside Git at `/workspace/kjnlae-v04-work/annotation-bundle-v1`; it contains text from external sources and must not be committed or redistributed until the individual content licenses are cleared.

## Reproduce the private export

Install the optional training environment with `pyarrow`; acquire the pinned repositories and parquet privately. Verify their licenses and revisions. For example, from the project root:

```bash
python -m pip install '.[train]' pyarrow
git clone https://github.com/ethz-spylab/agentdojo.git /workspace/agentdojo-reference
git -C /workspace/agentdojo-reference checkout 089ed468cf3ed0322acc66b0211f26d9d90dbf60
git clone https://github.com/microsoft/BIPIA.git /workspace/bipia-reference
git -C /workspace/bipia-reference checkout a004b69ec0dd446e0afd461d98cb5e96e120a5d0
hf download neuralchemy/Prompt-injection-dataset core/test-00000-of-00001.parquet \
  --repo-type dataset --revision 7d70432dfcf47a821612cbf9d34e9d9e3ad20e75 \
  --local-dir /workspace/kjnlae-v04-work/independent-sources
python scripts/prepare_annotation_bundle.py \
  --agentdojo-checkout /workspace/agentdojo-reference \
  --bipia-checkout /workspace/bipia-reference \
  --neuralchemy-test /workspace/kjnlae-v04-work/independent-sources/core/test-00000-of-00001.parquet \
  --output /workspace/kjnlae-v04-work/annotation-bundle-v1
```

The exporter exits if the destination already exists, any checkout has modified tracked files, or a pinned hash differs. ## Human review and freeze criteria

At least two independent reviewers should label each proposed final family without seeing upstream labels or model predictions. `review_label=1` means an instruction in a lower-trust surface attempts to redirect an assistant from the legitimate task or authority boundary. An ordinary direct user request for another person's record is **not** automatically an injection; authorization decides whether that access is allowed. `review_label=0` includes relevant instructions from the authorized user, benign documents, explanations, quoted payloads and code/test data that do not direct the assistant. Mark unclear cases for adjudication and record a concise reason; do not silently coerce them to either class. Reviewers should also assign a stable family ID, source, task, license eligibility, and whether the content is complete under the model's input limits.

Resolve disagreements without seeing model output, then exclude uncertain or license-restricted rows where necessary. Add independently authored and reviewed benign quotations, documentation, code, RAG, email, tool-output and webpage cases; this candidate pool has no webpage coverage. Check family and text overlap against all historical and new TRAIN/VALIDATION/CALIBRATION material, including near duplicates. Freeze the final rows, reviewer adjudication, split manifest and SHA-256 **before** inspecting a new candidate's final-set predictions. If the reviewed pool falls short of at least 1,000 benign and 500 attack independent families and the stated source minima, report the gap. Do not derive a threshold from this set. Maintain a separate AgentDojo end-to-end action outcome report; a classifier label is not attack prevention.
