# PR 2 review text: sealed evaluation and external diagnostic

**Base:** `fix/v0.3-phase0-readiness`

**Head:** `feat/v0.4-independent-evaluation`
**Status:** experimental evaluation tooling; no model publication or default change.

This branch adds hash-pinned JSONL evaluation, verified TRAIN/VALIDATION/CALIBRATION overlap checks, complete-only model metrics, and an importer for a pinned MIT-declared S-Labs TEST CSV. It runs the real local ONNX classifier through `Guard.scan`, records incomplete inspections separately, and never stores the external text in Git. An independent code review found and verified fixes for three evaluation defects: the CLI now invokes the overlap check, the checker accepts typed cases, and frozen final cases reject near-duplicate families.

At the existing thresholds, all 2,101 external direct-user rows were inspected. The v0.3 candidate produced TP/TN/FP/FN **692/1046/4/359** (precision 99.43%, recall 65.84%, benign FPR 0.38%). The public v0.2 control produced **869/960/90/182** (precision 90.62%, recall 82.68%, benign FPR 8.57%). Labels were not changed or excluded. They are unreviewed and some are ambiguous; the CSV is short-prompt and single-source, so these are diagnostic results, not deployment estimates. The candidate's authored 120-case fixture separately had **9/80 benign false alarms**. These observations fail the approved limited-beta evidence gate, and the required reviewed multi-source final set is not yet available. The v0.2 historical-development overlap check is partial; details and exact hashes are in the [report](v0.4-external-diagnostic.md).

Local `KJNLAE_VERIFY_RELEASE=1 bash scripts/verify_all.sh` with real candidate artifacts passed **141 Python tests, 1 skipped**, Ruff, mypy, 7 frontend tests, frontend build, wheel build, real-model doctor and fixture benchmark. Hosted [quality run #155](https://github.com/namelessweakl1ng/kjnlae/actions/runs/39147630075) passed for the evaluated code; later documentation-only runs must be checked before merge. The production frontend audit found zero vulnerabilities. A broader optional training-environment audit found known advisories in Transformers 4.51.3 and setuptools 78.1.0; the default ONNX runtime does not import them.

Review the split-independence check, incomplete-report behavior, label provenance and honest release claims. Do not merge this evaluation work as a production-model approval. No weights were committed, no Hugging Face repository was changed, and the v0.2 public installer remains pinned for rollback.
