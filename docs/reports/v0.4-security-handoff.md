# v0.4 security and review-bundle handoff

**Status (2026-10-19): experimental; production gate open.** This branch fixes an in-memory tenant/resource identity collision and prepares a private, blinded candidate bundle for later label review. It does not train or publish new weights, change the public default model, or establish release accuracy. The [external diagnostic](v0.4-external-diagnostic.md) remains a serious blocker: the current v0.3 candidate missed 359 of 1,051 upstream-labeled attacks on the pinned S-Labs direct-user set. Those labels have their own ambiguities and are not the reviewed multi-source final set.

The tenant fix keys resource lookup, version checks, action execution and output release by both tenant and resource ID. A legacy unscoped lookup succeeds only when the ID is unique. Synthetic chatbot documents use the same scoped identity. Regression tests cover two tenants sharing an ID and ensure one tenant cannot access the other's content. Prompt-injection classification remains independent of those grants.

The [annotation bundle](v0.4-annotation-bundle.md) contains 1,718 distinct candidate strings from pinned sources with upstream labels sealed separately. Human reviewers have **not** labeled or adjudicated it. It lacks webpage cases and has unknown family independence and license eligibility. No final-set score or retraining decision may rely on it yet.

The four skips are optional integration paths and are not claimed as executed.

With `HF_HUB_OFFLINE=1` and the verified local ONNX artifact, `kjnlae doctor` and `kjnlae scan --text ...` executed. The one-off benign direct-user text `Summarize this public memo.` returned `REQUIRE_REVIEW` at score 0.9999, another concrete false alarm. An individual scan is not a performance measurement.
- `npm audit --omit=dev` found **0** known production frontend vulnerabilities. A fresh wheel-plus-API environment with an updated `pip` returned **0** known vulnerabilities from `pip-audit`. The broader maintainer environment returned **32** advisories in optional `transformers 4.51.3` (28) and `setuptools 78.1.0` (4); these remain relevant to training/build workflows. Before upgrading either, rerun exact training reproducibility and artifact parity checks.

The build was canceled without a completed image, so this branch has **no Docker runtime smoke result**. This is an environment/network verification gap, not evidence of a passing container.
