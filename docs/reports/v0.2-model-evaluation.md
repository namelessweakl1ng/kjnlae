# v0.2 local model evaluation — measured 2026-10-13

The final model is a genuinely fine-tuned English `distilbert/distilbert-base-uncased` encoder plus classification head, starting from Apache-2.0 revision `12040accade4e8a0f71eabdb258fecc2e7e948be`. Training ran on four CPU cores using PyTorch 2.6.0+cpu and Transformers 4.51.3. No GPU, hosted model, model fallback or simulated optimizer was used.

The final run used 660 TRAIN examples (64 original fictional, 50 pinned Microsoft BIPIA attack prompts, 546 pinned Deepset train cases), 12 separate original VALIDATION cases, 12 original CALIBRATION cases and 116 untouched Deepset official test cases. TRAIN class counts were 375 non-injection and 285 injection; class weights were 0.88 and 1.1579 respectively. The exact split files and provenance hashes are in the local `var/data/prepared-v2/manifest.json`; source licenses and limitations are described in `docs/model-data.md`.

The 128-token, batch-2, FP32 run completed 660 optimization steps in two epochs. Epoch 2 was selected on VALIDATION F1 at the predeclared 0.5 threshold (0.8 on 12 examples). Worker time was 251.66 s; watchdog wall time was 253.86 s, below the 300 s cap. Peak worker RSS was 1,959,120,896 bytes (1.82 GiB) and peak cgroup use was 18,100,715,520 bytes (16.86 GiB). Initial weights SHA256 `82c89acc833e07cef4238a36f4150f267083c0015c318060514ea03777eaf9a4` differ from selected trained weights SHA256 `9c5db8696438f9fdee8e2982f468abaa5f894883a16e2926cba5849d8d858882`; exact epoch losses are in the local `var/models/full-v0.2-public/fit-report.json` (SHA256 `aa20762b02aef7eb991b278420641e10b5162a2c4fb671c0cb2dc36fc753e75d`).

CALIBRATION chose a threshold independently for each model; HELD_OUT_TEST was evaluated only after training and threshold choice. Scores are model outputs, **not** calibrated probabilities of attack success.

The control is **not** a pretrained prompt-injection detector. The comparison shows the effect of our training against a seeded untrained head on this one split; it does not establish superiority over external detectors. With only 116 test cases, zero observed false positives does not imply zero deployment false positives. The source mix, paraphrases, multilingual attacks, long documents, decoded payloads and real hospital/enterprise workflows need broader independent evaluation. Worker startup, preprocessing, tokenization, serialization and policy overhead are **not** included in the reported forward-pass mean; measure end-to-end latency separately.

An earlier, exploratory 114-TRAIN run on 12 original test examples yielded fine-tuned TP=5, TN=4, FP=2, FN=1 (F1=0.769; FPR=0.333), including a benign employee-access question misclassified by the model. This finding motivated broader public training data. Those 12 test examples were excluded from the final official-test manifest, and their results must not be mixed into the final 116-case confusion matrix. Iterative development after observing the exploratory test means the overall research process is not a single untouched preregistered experiment.
