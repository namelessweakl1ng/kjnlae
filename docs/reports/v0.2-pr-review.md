## Experimental v0.2 implementation

kjnlae now uses its own fine-tuned English DistilBERT as the sole prompt-injection detector. The scanner performs bounded preprocessing, complete-window inference, source/evidence mapping, and explicit `INCOMPLETE` results when the verified local model cannot inspect input. There is no regex/rule detector, untrained-model fallback, or claim that a suspicious scan proves an attack succeeded. The React dashboard, CLI, SDK, FastAPI `/v2` endpoints, RAG example, and scripted hospital/enterprise examples use the same model-only path.

Independent host-owned action and output controls enforce authenticated principal, tenant and resource grants, tool/destination restrictions, exact parameter-bound approvals, resource-version checks, and known-secret/data-release rules. In the six scripted sandbox cases, both authorized public-read tasks completed and all four unauthorized actions were denied, including one detector miss. This is not a live-LLM attack-success measurement.

## Training and measured results

The Apache-2.0 DistilBERT base is pinned to revision `12040accade4e8a0f71eabdb258fecc2e7e948be`. Public licensed TRAIN examples and original fictional synthetic examples were prepared with separate TRAIN (924; 639 benign/285 attack), VALIDATION (12), CALIBRATION (12), and held-out Deepset TEST (116) partitions. An independent authored 50-case fixture was committed before retraining and never entered training, selection, or calibration. The four-core CPU training run completed two epochs/924 optimizer steps in 351.13 seconds, peak worker RSS 1.89 GB; validation selected epoch 1, so deployed weights represent 462 steps. Calibration picked threshold 0.02513 from only 12 rows. The reviewed manifest explicitly labels the model `EXPERIMENTAL`, verifies safetensors/file hashes, and is pinned by SHA-256.

This is a **mixed result**. False positives remain serious: 9/12 benign original regression cases and 10/35 benign new cases were flagged. The Deepset held-out FPR worsened. Neither small fixture is representative of deployment traffic, scores are not calibrated attack-success probabilities, and this project is not production-ready. External AgentDojo/BIPIA benchmarks were not run.
