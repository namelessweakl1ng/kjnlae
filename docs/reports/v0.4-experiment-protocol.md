# v0.4 independent-evaluation protocol — preliminary external diagnostic

**Status:** frozen external *diagnostic* source, before scoring the v0.3 candidate on it. This is not the new multi-source final set required by the [production-readiness design](../superpowers/specs/2026-10-18-production-readiness-design.md). Do not use these TEST labels or scores to tune training, select a threshold, or promote a model. The existing 30/50/120-case and Deepset TEST results are already opened historical diagnostics.

## Pinned external source

The S-Labs `prompt-injection-dataset` [test split](https://huggingface.co/datasets/S-Labs/prompt-injection-dataset) is pinned to immutable repository revision `002a9dd18514abd021869823d6b0429b38606d99`, file `data/test.csv`, SHA-256 `4c7a9f0fff2bf7d3f6d3e7b84863a8f5d6c48c70c3ac7fe874917074c8f27853`. The card declares MIT. The 2,101 rows contain 1,050 label-0 and 1,051 label-1 texts, all distinct under exact and NFKC/casefold comparison. The adapter records them as `source=user` because the card describes direct user input; it does not invent webpage, RAG, email or tool-response provenance. No source rows are committed or republished here.

Before scoring, the imported rows were compared against all 884 local v0.3 TRAIN rows. No shared family ID, normalized text, or high-similarity text was detected using the repository's 0.85 similarity screen. This does not exclude semantic overlap, overlap with encoder pretraining, internal correlation among the external rows, or benchmark exposure elsewhere. The source card's labels are **unreviewed** by this project. A manual sample contains ambiguous attack labels, including ordinary questions about guidelines and configuration. Its largely short, synthetic prompts and balanced prevalence are not representative of deployed applications. It can reveal distribution shifts but cannot meet a production gate, even if its aggregate score is high.

## Reproduction

From a clean checkout with an explicitly installed and verified ONNX model, download the immutable CSV into a local ignored directory:

```bash
mkdir -p var/evaluation
curl -fL 'https://huggingface.co/datasets/S-Labs/prompt-injection-dataset/resolve/002a9dd18514abd021869823d6b0429b38606d99/data/test.csv' -o var/evaluation/s-labs-test.csv
sha256sum var/evaluation/s-labs-test.csv
python scripts/evaluate_release.py --s-labs-csv var/evaluation/s-labs-test.csv --development-dir /path/to/v0.3-prepared --development-manifest-sha256 d658aa61583e1efca4444f927d4cfa11c337e3f6fb3a01c58f8a1d0e83f0e31e --model-dir /path/to/verified-onnx --model-hash VERIFIED_MANIFEST_SHA256 --output var/evaluation/s-labs-report.json
```

The prepared v0.3 development directory can be rebuilt from the [training guide](../model-training-v0.3.md); its local manifest must match the SHA above and every TRAIN/VALIDATION/CALIBRATION split hash. The adapter refuses a changed source digest, and the CLI refuses a final/development family, normalized-text or near-duplicate overlap. The command uses `Guard.scan` with a verified local model, records every case and latency, and withholds whole-set accuracy if any case is incomplete. Its output path must be new. The report names the model manifest, development manifest and dataset digest. To compare v0.2 and v0.3, run the same pinned file in separate output paths; do not change their reviewed thresholds based on these results.

## Future final set

The separately reviewed production-candidate final set still needs at least 1,000 benign and 500 attack **independent content families**, spanning claimed sources at the per-source minima in the design. It needs reviewed injection-versus-ordinary labels, hard benign quotations/code, long and tail-position attacks, licensed provenance, a fixed split hash, and exact/normalized/near-duplicate checks against *all* development data. Freeze that set before further tuning and score it only after a candidate and threshold are fixed. External BIPIA classifier evaluation and genuine AgentDojo end-to-end tasks will be reported separately from this direct-user diagnostic and from authorization tests.
